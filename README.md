# 驿站波次装车台（城市末端配送模拟改造）

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia、localStorage
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务闭环

1. **订单登记**：录入订单号、站点、温区（常温/冷藏/冷冻）、到站时刻、承诺送达窗口（HH:mm 起与止）、收货人。
2. **按站点与温区分波**：同一 `站点 + 温区` 的待发订单自动归为同一波，波次按该组合的发车历史顺序编号。
3. **发车拦截（整批停住）**：点击发车时依次判定——
   - 波次容量：在站单数超过单波容量上限；
   - 冷链滞留：冷藏/冷冻订单从到站到当前的滞留分钟数超过温区上限；
   - 送达窗口倒序：先到站的订单承诺窗口结束更晚、后到站的反而更急（装车会压住急单），或窗口起止本身倒置。
   任一冲突即整批停发，订单录入内容原样保留，界面明确指出**站点、波次号、冲突规则与涉及订单号**。
4. **冻结与补签**：发车后装车清单（含装车顺序）生成快照冻结，订单移出待发区；补签不修改旧单，而是带原因另存一个版本，版本链可随时切换核对。
5. **重开可核对**：订单、规则、清单、版本、逐单勾选进度全部保存在浏览器 localStorage，刷新或重开页面后仍可沿波次核对。

## 分层结构（数据 / 判定 / 界面独立）

- `src/types.ts`：领域模型。
- `src/domain/rules.ts`：**判定层**，全部为纯函数（分波、窗口排序、三类冲突校验、冻结快照、补签版本），不依赖存储与 DOM。
- `src/data/dockStore.ts` 与 `src/data/seed.ts`：**数据层**，Pinia store、localStorage 持久化与演示种子；本身不写判定规则，一律调用 domain。
- `src/components/*` 与 `src/App.vue`：**界面层**，登记表单、待发波次卡、冻结清单卡；只派发动作和展示结果。
- `src/utils/time.ts`：纯时间工具。
