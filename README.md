# 驿站波次装车台

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

城市末端配送模拟改造为驿站波次装车台：

- **订单登记**：录入到站时刻、温区（常温/冷藏/冷冻）与承诺送达窗口，按站点 + 温区自动分波；无匹配波次时进入待入波池。
- **整批发车停住**：波次容量超限、冷链滞留超限或送达窗口倒序任一冲突出现时，整批发车停住，录入内容保留，并指出具体站点、波次与订单。
- **清单冻结与补签**：发车后装车清单冻结为 v1；补签另存为带原因的新版本（v2、v3…），旧版清单原样保留。
- **持久化**：数据保存在浏览器 localStorage，重开页面后可沿波次继续核对。

## 分层

- `src/domain/types.ts` —— 数据层：订单、波次、清单版本等结构定义。
- `src/domain/rules.ts` —— 判定层：纯函数校验容量、冷链滞留、窗口倒序，不依赖存储与界面。
- `src/data/store.ts` —— 持久化层：localStorage 读写、发车冻结、补签追加版本。
- `src/App.vue` —— 界面层：只负责渲染与交互。
